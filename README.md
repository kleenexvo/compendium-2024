## Installation

### Automatic Installation (Recommended)

1. Open **Foundry VTT**
2. Go to **Settings → Module Management**
3. Click **Install Module**
4. Paste the following URL in the manifest field:

https://raw.githubusercontent.com/kleenexvo/compendium-2024/refs/heads/main/module.json

5. Click **Install**

## Compatibility

- **Foundry VTT**: v14+
- **System**: D&D 5e
